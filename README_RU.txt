InstantHomes — исходный проект мода для Minecraft Java 26.3 / Forge 66.1.0

ВАЖНО: это исходники, а не проверенный готовый JAR. В этой среде нет Java 25, Gradle и доступа к Maven Forge, поэтому собрать и запустить мод здесь не получилось. Не устанавливайте исходный ZIP в папку mods: Minecraft принимает только собранный JAR.

Требования:
- Minecraft Java 26.3
- Forge 26.3-66.1.0
- Java 25
- Gradle wrapper из официального MDK Forge 26.3-66.1.0

Как собрать:
1. Скачайте MDK с официальной страницы Forge: https://files.minecraftforge.net/net/minecraftforge/forge/
2. Распакуйте MDK в отдельную папку.
3. Скопируйте из этого архива папку src в папку MDK, заменив совпадающие файлы.
4. В MDK замените mod_id на instanthomes, mod_group_id на ru.instant.homes, mod_version на 1.0.0, minecraft_version на 26.3 и forge_version на 66.1.0 в gradle.properties, если такие ключи присутствуют.
5. Запустите gradlew.bat build.
6. При успешной сборке JAR будет в build\libs. Скопируйте его в .minecraft\mods.

Команды:
/sethome — основной дом
/sethome <название> — создать/обновить дополнительный дом
/home — основной дом
/home <название> — дополнительный дом
/delhome <название> — удалить дополнительный дом
/tp <x> <y> <z> — координаты в текущем измерении

Данные записываются в SavedData мира (в Overworld), включая измерение и направление взгляда. Команды /home и /tp используют штатный механизм телепортации без таймеров/кулдаунов.

ОГРАНИЧЕНИЯ, КОТОРЫЕ НУЖНО ПРОВЕРИТЬ:
- Точная компиляция API под Forge 66.1.0 не подтверждена.
- Vanilla уже имеет команду /tp с ограничениями разрешений; объединение аргументов /tp в Forge необходимо проверить в одиночной игре без читов. Если ванильное ограничение перекроет команду, потребуется отдельная интеграция с механизмом прав Forge.

Более простой способ для Windows:
1. Установи Java 25.
2. Запусти СОБРАТЬ_МОД.bat двойным щелчком при подключённом интернете.
3. Скрипт скачает официальный MDK Forge 26.3-66.1.0 и попробует собрать JAR.
4. Если сборка прошла, JAR появится рядом с этим BAT-файлом.

Если скрипт выдаст ошибку компиляции, значит API в исходниках нужно уточнить под скачанный MDK; скрипт не скрывает ошибки и не заявляет успех без найденного JAR.
