КАК ПОЛУЧИТЬ JAR БЕЗ УСТАНОВКИ JAVA НА СВОЙ КОМПЬЮТЕР

В архив добавлен GitHub Actions workflow. Он запускает сборку на облачном компьютере GitHub с Java 25 и официальным MDK Forge 26.3-66.1.0. Сам JAR заранее не собран и должен быть получен после выполнения workflow.

1. Создай аккаунт на GitHub, если его ещё нет: https://github.com/
2. Нажми + в правом верхнем углу сайта, затем New repository.
3. Назови репозиторий InstantHomes, выбери Public или Private, нажми Create repository.
4. На странице нового пустого репозитория выбери ссылку "uploading an existing file".
5. Распакуй архив на компьютере. Открой папку InstantHomes-Forge-26.3 и загрузи ВСЕ её файлы и папки в GitHub, включая скрытую папку .github. Если загрузчик браузера не показывает .github, используй GitHub Desktop или веб-интерфейс создания файлов; папка workflow обязательна.
6. Внизу страницы нажми Commit changes.
7. Открой вкладку Actions. Если GitHub попросит разрешить Actions, подтверди.
8. Выбери "Build InstantHomes JAR" слева и нажми Run workflow, если запуск не начался автоматически после commit.
9. Дождись зелёной галочки. Открой завершённый запуск, пролистай вниз до Artifacts и скачай InstantHomes-JAR.
10. Распакуй скачанный артефакт. Внутри должен быть файл InstantHomes-*.jar. Перенеси его в папку mods профиля Forge 26.3 в TLauncher.

ВАЖНО: Это способ автоматически попробовать собрать мод, а не гарантия успешной сборки. Если сборка упадёт, открой запуск Actions и скопируй сюда последние строки ошибки из шага "Build mod with official Forge MDK". Не публикуй токены, пароли или секреты.
